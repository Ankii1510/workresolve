# NOTE ON `genlayer`: the real GenVM runtime package is NOT pip-installable
# in a normal Python environment — `genlayer` on PyPI is a placeholder
# (`genlayer==0.0.1`, "a minimal empty package"). The actual runtime is
# provided by GenVM itself when a contract is deployed (declared via the
# `# { "Depends": "py-genlayer:<hash>" }` header at the top of
# contracts/workresolve.py), and by GenLayer Studio / a testnet node when
# running gltest. There is deliberately no `genlayer` pin below — installing
# it here would install the placeholder and create a false sense that the
# real SDK is available locally. See docs/contracts.md "Known Limitations".

genlayer-test==0.1.1
